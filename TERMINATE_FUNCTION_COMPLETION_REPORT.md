### 1. Модификация функции Terminate() в uacuas.go

#### Реализованные улучшения:
- Добавлена проверка состояния IDLE с генерацией события перехода в Ended
- Улучшена обработка состояния Terminating для предотвращения дублирования вызовов
- Добавлен информативный контекст для всех переходов состояний
- Сохранена обратная совместимость с существующим API

#### Ключевые изменения кода:
```go
// Проверка состояния IDLE
if self.getState() == IDLE {
    self.setState(Ended, StateChangeContext{
        Reason:  "Dialog terminated in IDLE state",
        Details: "No active call to terminate",
    })
    return nil
}

// Обработка состояния Terminating
if self.getState() == Terminating {
    return fmt.Errorf("dialog already terminating")
}
```
